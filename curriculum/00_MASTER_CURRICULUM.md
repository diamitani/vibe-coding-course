# Vibe Coding Masterclass — Master Curriculum

## Overview

The Vibe Coding Masterclass is a comprehensive, project-based curriculum designed to take learners from zero coding experience to confidently building production-quality software using AI-powered development tools. The curriculum blends foundational AI literacy, practical tooling, prompt engineering, and hands-on project work.

**Platform:** Vibe Coding Masterclass (vibecodingcourse.z20.web.core.windows.net) + LetsVibeAI (letsvibeai.com)

**Estimated Total Time:** ~20 hours

**Cost:** Free

**Difficulty Progression:** Beginner → Intermediate → Advanced

## Learning Objectives

By completing this curriculum, learners will be able to:

1. **Understand AI fundamentals** — Explain how large language models work, what tokens and context windows are, and why AI transforms software development.
2. **Apply the vibe coding loop** — Describe → Generate → Review → Refine with confidence across multiple tools.
3. **Select and combine tools** — Choose the right AI development tool for any project type and combine them into powerful workflows.
4. **Engineer prompts effectively** — Chain prompts for complex tasks, manage context budgets, and design reproducible processes.
5. **Build and ship real projects** — Plan, build, test, and deploy full-stack applications using AI-assisted development.
6. **Design AI workflows** — Create standardized, team-ready processes for production vibe coding.
