# Ten-Day AI Bootcamp

A rapid, structured learning path that condenses the full Vibe Coding Masterclass into 10 daily sessions. Designed for cohort-based programs, hackathons, or self-paced learners who want a clear day-by-day schedule.

**Total Time:** ~20 hours (2 hours/day)

**Outcome:** A deployed, portfolio-ready project and the skills to continue building independently.

---

## Schedule

### Day 1 — AI Foundations

**Content:** Module 1 (What Is AI)

- Core concepts: machine learning, LLMs, tokens, context windows
- How transformers work (high level)
- Current model landscape
- Hands-on: Use 3 different AI models on the same prompt, compare outputs

**Deliverable:** A one-page cheat sheet explaining how LLMs work

### Day 2 — Vibe Coding Mindset

**Content:** Module 2 (What Is Vibe Coding)

- The vibe coding loop: Describe → Generate → Review → Refine
- Traditional dev vs. vibe coding
- When to vibe code, when not to
- Hands-on: Generate a single-page website from a text description

**Deliverable:** A live "Hello World" page deployed to a public URL

### Day 3 — Tool Familiarization

**Content:** Module 3 (The Toolkit)

- Tool categories: hosted builders, AI IDEs, CLI agents, backend services
- Compare 3 tools on the same task
- Build your personal tool stack
- Hands-on: Scaffold a 3-page site in Lovable, v0.dev, and Bolt.new

**Deliverable:** A tool comparison matrix with notes on each

### Day 4 — Prompting Fundamentals

**Content:** Module 4 (Prompt Chaining)

- Why chaining beats one-shot
- The Plan → Generate → Review pattern
- Error handling and retry strategies
- Hands-on: Chain 3 prompts to build a feature from spec to code

**Deliverable:** A documented 3-step prompt chain

### Day 5 — Context Mastery

**Content:** Module 5 (Context Engineering)

- Context windows and token budgets
- Structuring information for clarity
- Prioritization within limited context
- Iterative refinement
- Hands-on: Engineer a context pack for a 10-file codebase

**Deliverable:** A reusable context template (XML format)

### Day 6 — Workflow Design

**Content:** Module 6 (Process Engineering)

- From casual prompting to production workflows
- Quality gates and validation
- Documentation and SOPs
- Hands-on: Document a process for "generate a React component with tests"

**Deliverable:** A process documentation template

### Day 7 — Build Sprint 1

**Content:** Lab 1 (Marketing Website)

- Scaffold a complete marketing site
- Iterate on design
- Add all pages and content
- Deploy to production

**Deliverable:** Live marketing website at a public URL

### Day 8 — Build Sprint 2

**Content:** Lab 2 (E-Commerce Store, scaffold)

- Product catalog scaffold
- Cart implementation
- Checkout flow basics
- Deploy preview

**Deliverable:** E-commerce store scaffold with cart and catalog

### Day 9 — Build Sprint 3

**Content:** Lab 3 (Marketplace, scaffold)

- Database schema design
- Listing management
- Search and filtering
- Deploy preview

**Deliverable:** Marketplace scaffold with listings and search

### Day 10 — Ship + Portfolio

- Final polish on any project
- Custom domain setup
- Write project README
- Submit to portfolio gallery
- Review bootcamp learnings

**Deliverable:** Portfolio-ready project with documentation and live URL

---

## Daily Cadence

Each day follows the same structure:

```
Warm-up (15 min)    — Review previous day, set today's goal
Learn (30 min)      — Read/watch core content
Practice (45 min)   — Hands-on exercise
Build (30 min)      — Apply to your project
Review (15 min)     — Reflect, document, share progress
```

---

## Facilitator Guide (for cohorts)

### Preparation

- Set up a shared community space (Discord, Slack, or Circle)
- Create cohorts of 5-10 learners
- Schedule a 30-min kickoff call before Day 1
- Prepare a template repo with starter code

### Daily Check-Ins

Start each day with:
1. What did you build yesterday?
2. What was the hardest part?
3. What's one thing you'd do differently?

### Review Sessions

Mid-point review after Day 5:
- Quick-fire demos (2 min each)
- Peer feedback
- Troubleshooting common issues

Final review after Day 10:
- Portfolio presentations (5 min each)
- Live demo
- Lessons learned

## Troubleshooting

| Problem | Solution |
|---------|----------|
| Fallen behind schedule | Skip Days 1-3 reading, jump to hands-on exercises |
| Tool isn't working | Switch to a different tool from the same category |
| Project too ambitious | Strip features, focus on core functionality |
| Overwhelmed by concepts | Focus on the vibe coding loop only, skip theory |
| Deployment failing | Use the simplest option (Vercel auto-deploy from GitHub) |
