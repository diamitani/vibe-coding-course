🧠 Module 1 — What is AI?

▼

Duration: ~2-3 hours | Difficulty: Beginner | Status: Free

Overview

Before we build with AI, we need to understand what's under the hood. This module covers the fundamentals of artificial intelligence, how large language models work, and why this technology changes the way people learn, work, and build software.

Topics Covered

  • Machine Learning vs Rule-Based Systems
  • How Large Language Models (LLMs) Work
  • Tokens and Context Windows
  • Generative AI and Transformers
  • Why AI is Transforming Software Development
  • The Current Landscape of AI Models

What You'll Learn

  • The difference between supervised, unsupervised, and reinforcement learning
  • How transformers make LLMs understand context
  • Why token limits matter and how to work within them
  • The capabilities and limitations of modern AI

🎯 Module 2 — What is Vibe Coding?

▼

Duration: ~2 hours | Difficulty: Beginner | Status: Free

Overview

Vibe coding is the practice of building software by describing what you want in natural language and letting AI generate the code. Learn how this fundamental shift is reshaping who can build technology.

Topics Covered

  • Origin Story: Where the Term Came From
  • How Vibe Coding Works: The Loop
  • Real-World Use Cases and Examples
  • Traditional Development vs Vibe Coding Mindset
  • The Future of Software Development

What You'll Learn

  • The vibe coding loop: Describe → Generate → Review → Refine
  • How to shift from writing code to directing AI
  • Real projects being built with vibe coding
  • Why this represents a paradigm shift in software

→ Start Module 2

🛠️ Module 3 — The Toolkit

▼

Duration: ~3 hours | Difficulty: All Levels | Status: Free

Overview

There are dozens of AI-powered tools for vibe coding. Learn which tools fit different workflows and build styles. Compare Lovable, v0.dev, Replit, Bolt.new, and many more.

Tools Covered

  • Hosted Builders: Lovable, v0.dev, Bolt.new, Replit, Framer AI, Webflow
  • AI IDEs: Cursor, GitHub Copilot, Windsurf, Antigravity
  • CLI Agents: Claude Code, Aider, Codex
  • Backend Services: Supabase, Firebase, Convex
  • Deployment Platforms: Vercel, Netlify, Railway

What You'll Learn

  • The pros and cons of each tool category
  • Which tools work best for different project types
  • How to combine tools into a powerful workflow
  • Best practices for each platform

→ Start Module 3

⛓️ Module 4 — Prompt Chaining

▼

Duration: ~2-3 hours | Difficulty: Intermediate | Status: Free

Overview

Master the art of breaking complex requests into sequences of smaller prompts. Learn how prompt chaining leads to better results and more reliable AI-generated code.

Topics Covered

  • Why Prompt Chaining Works Better Than One-Shot Prompts
  • Structuring Multi-Step Workflows
  • Handling Failures and Edge Cases
  • Real-World Chaining Patterns
  • Tools for Managing Chains

What You'll Learn

  • How to break complex tasks into sub-tasks
  • The pattern of context seeding for better results
  • Error handling and retry strategies
  • How to chain outputs from one prompt as inputs to the next

▼

Overview

Topics Covered

  • Understanding Context Windows and Token Limits
  • What Information Matters Most to AI

  • Prioritizing Content in Limited Context
  • Iterative Context Refinement

  • The importance of clear specifications
