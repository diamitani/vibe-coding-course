🟢 Set Up OpenCode

OpenCode is an open-source terminal AI coding agent you can run locally. Configure it with your API keys and you'll have a powerful AI assistant in your terminal.

1 Install OpenCode

Run this command in your terminal to install OpenCode globally:

npm i -g opencode-ai 📋

Requires Node.js 18+. Don't have Node? Download it here →

2 Configure Your API Key

Set your Anthropic key as an environment variable so OpenCode can use Claude:

export ANTHROPIC_API_KEY=your_key_here 📋

Add this to your ~/.zshrc or ~/.bashrc to persist it across sessions.

3 Run OpenCode in Your Project

Navigate to any project folder and start OpenCode:

opencode 📋

4 Try a Vibe Coding Prompt

Once OpenCode is running, paste in a refined prompt from your AI Workspace and watch it build your app.

Open AI Workspace →

💡 Pro tip: Use your AI Workspace to generate a refined prompt, then paste it into OpenCode to build the project — this is the core vibe coding workflow.
