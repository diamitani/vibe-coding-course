Let's begin.

### What you will build
A Make.com scenario that:
1. pulls the next uncontacted lead from Google Sheets
2. generates personalized company research with Perplexity
3. analyzes your own products to anchor the pitch
4. drafts a “body only” cold email with DeepSeek (or any chat LLM)
5. sends via Resend for solid deliverability
6. writes back a timestamp to the sheet so you never double-send
Costs and notes: free tiers cover most of this. Expect a couple dollars for LLM credits. Any promo offers change, so verify them at signup.

### Prerequisites
- Google account with a Sheet of leads
- [Make.com](https://www.linkedin.com/redir/redirect?url=https%3A%2F%2Fwww%2Emake%2Ecom%2Fen%2Fregister%3Fpc%3Dgptpat&urlhash=K63b&trk=article-ssr-frontend-pulse_little-text-block) account
- Resend account and a verified sending domain (SPF and DKIM set)
- Perplexity API key (or alternative: Google Gemini with web search, OpenAI with web search, or plain HTTP scraping)
- DeepSeek API key (or substitute any chat completion API)
- A custom domain email for sending, not a free mailbox
[Make.com](https://www.linkedin.com/redir/redirect?url=https%3A%2F%2Fwww%2Emake%2Ecom%2Fen%2Fregister%3Fpc%3Dgptpat&urlhash=K63b&trk=article-ssr-frontend-pulse_little-text-block)

### Your Google Sheet schema
Create a sheet named Leads with these headers (exact spellings help later):

```
first_name | last_name | email | company_name | company_domain | prospect_linkedin | title | source | status | email_1_date | email_1_message_id | notes
```

Leave email_1_date blank for new leads. That is your “ready to contact” flag.

### Scenario overview (Make.com)
High-level flow:
1. Google Sheets: Search Rows → filter for email_1_date is empty
2. Perplexity: Company Research
3. Perplexity: Your Company Knowledge Snapshot
4. DeepSeek: Draft “body only” email
5. Resend: Send the email
6. Google Sheets: Update the original row with now() and message ID
Run this as a scheduled scenario with a rate that respects warmup and daily caps.

### Step 1: Pull the next eligible lead from Google Sheets
- Module: Google Sheets → Search Rows
- Connection: your account
- Spreadsheet and sheet: select your leads file and Leads
- Query options:
- Add a Make filter immediately after this module:
Tip: If you want batching, use Limit 5–10 and add an Iterator to loop row-by-row.

### Step 2: Company research with Perplexity
You can use the Perplexity API via HTTP or a connector. The important part is the prompt and mapping.
Inputs to map from the row:
- company_name
- company_domain
- prospect_linkedin
Prompt template (system or user role is fine):

```
Research the company: - Company: {{company_name}} - Domain: {{company_domain}} - Prospect LinkedIn (if provided): {{prospect_linkedin}} Deliver a concise, factual brief: 1) What they do 2) ICP and segments they serve 3) Key products or features with 1–2 sentences each 4) Recent initiatives, hiring hints, or content themes that signal priorities 5) Pain points they likely have based on public info 6) 3 verifiable bullets with sources or URLs No fluff. No marketing language. Keep to 120–180 words.
```

Return JSON if possible or plain text you can map. Save the whole text to a company_research_summary variable.
Alternative options:
- Gemini with web enabled
- OpenAI with web enabled
- HTTP module to fetch the homepage and a couple subpages, then summarize with any LLM

### Step 3: Snapshot your own offerings as a knowledge base
Run a second research call so the writer model knows what you sell.
Inputs:
- Your primary domain (and optionally product pages or a simple “about” brief)
Prompt template:

```
You are my internal product summarizer. Visit and analyze: {{your_company_domain}} plus any obvious product/pricing/docs pages. Return a compact product snapshot: - Who we serve - 3–5 core problems we solve - Relevant capabilities or features with 1 sentence per item - 2–3 short customer outcomes Keep it neutral and concise, 80–120 words. No hype.
```

Save as my_product_snapshot.
Note: If you do not want web calls for your site every time, paste a short authoritative summary once, store it in Make’s Data Store, and reuse it.

### Step 4: Draft the “body only” cold email with DeepSeek (or any chat model)
Use a chat completion module or HTTP request. You will pass both research blocks.
System prompt:

```
You write short, plain-text B2B cold emails that get replies. No emojis. No hashtags. No asterisks. No em dashes. No greetings or sign-offs. Output must be the body only (no "Hi", no "Best"). 70–110 words. One call-to-action question at the end. Sound like a human who did their homework.
```

User prompt (mapped values in braces):

```
Company research: {{company_research_summary}} My product snapshot: {{my_product_snapshot}} Prospect: - First name: {{first_name}} - Title: {{title}} Write a single “body only” email that references something useful from the research and positions our product as specifically helpful. Suggest one next step relevant to their role. Do not include a subject line. Do not include any greeting. No emojis, hashtags, asterisks, or em dashes.
```

Save the output as email_body. Add a Make text sanitizer if needed to strip accidental greetings.
Optional: Generate a subject line in a separate call with strict rules like “7 words max, no punctuation except a single question mark.”

### Step 5: Send via Resend
- Module: Resend → Send Email (or HTTP to Resend API)
- From: Your Name <you@yourdomain.com> (must be a verified domain in Resend)
- To: map email
- Subject: either a static utilitarian subject or your generated subject
- Body:
- Capture messageId or returned identifier to log in the sheet
Deliverability checklist:
- Verify domain in Resend
- SPF and DKIM pass
- Start slow to warm up a new domain
- Keep links minimal and use your root domain if possible

### Step 6: Update the Google Sheet
- Module: Google Sheets → Update a Row
- Row ID: from the original search result
- Set email_1_date to now() (Make has a built-in now function)
- Set email_1_message_id to the value returned by Resend
- Optionally set status to sent_email_1
Now the next run will automatically skip this row.

### Step 7: Scheduling and throughput
- Start with a scheduler every 10–15 minutes sending 1–3 emails per run
- Respect Resend’s free tier limit and your domain warmup
- Increase batch size only after positive deliverability signals

### Optional upgrades
1. CRM-first workflow If you live in HubSpot or another CRM, replace Google Sheets with your CRM search. The same steps apply. Keep your timestamps and message IDs in CRM properties.
2. Follow-up sequence Add a router: if email_1_date is set and email_2_date is empty and days since email_1_date >= 3, run a second writer prompt that references the prior email and a new angle. Same send, then update email_2_date.
3. Safety, dedupe, and validation
- Add a “Validate email” step or a simple regex at minimum
- Filter domains like role accounts (info@, admin@) if you prefer not to mail them
- Add a “Do Not Contact” sheet and check against it
1. Subject line A/B testing Generate 2 variants, alternate by row parity, log which one was used.
2. Error handling
- If Perplexity or DeepSeek fails, write notes with the error and skip
- Use Make’s error handlers to retry transient failures

### Compliance notes
- Honor opt-out requests. Add an “opt_out” column and never mail opted contacts.
- Know your jurisdiction rules. CAN-SPAM, CASL, GDPR all exist. Include a reply-to and a business address where required.

Company research (Perplexity):

```
Research the company: - Company: {{company_name}} - Domain: {{company_domain}} - Prospect LinkedIn: {{prospect_linkedin}} Return 120–180 words: 1) What they do 2) ICP and segments 3) Key products or features 4) Recent initiatives or themes with sources 5) Likely pain points 6) 3 bullets with URLs Factual and concise. No hype.
```

Your product snapshot:

```
Analyze {{your_company_domain}} and obvious product/pricing/docs pages. Return 80–120 words covering: - Who we serve - 3–5 problems we solve - 3–5 capabilities - 2–3 short customer outcomes Neutral tone. Concise.
```

Cold email “body only” (DeepSeek or any LLM):

```
You write short, plain-text B2B cold emails that get replies. No emojis, hashtags, asterisks, or em dashes. Output must be the body only (no greeting, no sign-off). 70–110 words. Exactly one question CTA. Company research: {{company_research_summary}} My product snapshot: {{my_product_snapshot}} Prospect: First name: {{first_name}} Title: {{title}} Write one “body only” email that references something useful from the research, ties our capability to their likely priority, and ends with a single question about a next step.
```

Subject line (optional):

```
Generate 1 subject line. 5–7 words. No punctuation except a single question mark if needed. No proper nouns unless in {{company_name}}. Must be specific to the body content.
```

### Final checklist
- Sheets columns created and sample rows added
- Resend domain verified with SPF and DKIM
- Make scenario tested with one row
- Timestamps and message IDs logging correctly
- Scheduler enabled with sane pacing
Ship this exactly, then layer in follow-ups and CRM sync. Keep it tight, keep it factual, and keep sending.
