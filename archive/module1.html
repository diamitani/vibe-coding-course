🧠 What is AI?

Introduction

Artificial Intelligence has transformed from a buzzword into the most important technological shift of our generation. But what actually is it?

At its simplest, AI is the ability of machines to perform tasks that normally require human intelligence. This includes understanding language, recognizing patterns, making decisions, and generating creative content.

The AI we interact with today — tools like ChatGPT, Claude, Gemini, and Copilot — is a specific type called generative AI. Unlike older AI systems that could only classify or predict, generative AI can create new content: text, images, code, music, and more.

Key Insight: Modern AI doesn't "think" like humans do. It predicts the next most likely word, pixel, or sound based on patterns learned from massive amounts of training data. The magic isn't consciousness — it's pattern matching at an unprecedented scale.

Machine Learning vs Rule-Based Systems

To understand AI, you need to understand the difference between two fundamental approaches:

Rule-Based Systems

Traditional software follows explicit rules written by programmers. If X happens, do Y. These systems are predictable but brittle — they can only handle scenarios the programmer anticipated.

  • Example: A calculator — you give it 2+2, it returns 4. Every time.
  • Strength: Deterministic, predictable, easy to debug
  • Weakness: Cannot handle novel situations or ambiguous input

Machine Learning

Machine learning flips this approach. Instead of writing rules, you show the system examples and it learns the rules on its own. The system identifies patterns in data and uses those patterns to make predictions or decisions.

  • Example: Show an ML system 10,000 photos of cats and dogs without telling it which is which. Over time, it learns the patterns that distinguish cats from dogs.
  • Strength: Can handle ambiguity, adapts to new data, discovers patterns humans might miss
  • Weakness: Needs lots of data, can be unpredictable, hard to debug

Three Types of Machine Learning:

  • Supervised Learning: Training with labeled data (e.g., "this is a cat")
  • Unsupervised Learning: Finding patterns in unlabeled data
  • Reinforcement Learning: Learning through trial and error with rewards/punishments

How Large Language Models (LLMs) Work

LLMs are the engine behind ChatGPT, Claude, Gemini, and most modern AI tools. Here's a simplified version of how they work:

Training Phase

An LLM is trained on an enormous corpus of text — think millions of books, billions of web pages, and vast amounts of code. During training, the model learns statistical patterns: which words tend to follow which other words, how grammar works, what concepts are related, and even reasoning patterns.

Inference Phase

When you give an LLM a prompt, it doesn't "think" about your question. Instead, it generates a response one token at a time, each time predicting the most likely next token based on everything it learned during training and the context of your conversation.

Analogy: An LLM is like an infinitely knowledgeable autocomplete. You start typing, and it predicts what comes next — but it's been trained on so much data that its predictions are remarkably coherent and useful.

Key Capabilities

  • Text Generation: Writing articles, emails, code, poetry
  • Question Answering: Responding to queries with relevant information
  • Translation: Converting between languages
  • Summarization: Condensing long documents into key points
  • Reasoning: Working through logic problems step by step
  • Code Generation: Writing and explaining source code

Tokens and Context Windows

Two concepts are essential to understanding how to work effectively with AI:

What Are Tokens?

Tokens are how AI models measure text. A token is roughly 3/4 of a word in English, but it varies. "Hello" might be one token; "unbelievably" might be three tokens ("un", "believe", "ably"). Punctuation and spaces also count.

  • 100 tokens ≈ 75 words
  • Models charge by tokens (both input and output)
  • Response quality depends on tokens allocated to reasoning

Context Windows

The context window is the amount of text an AI model can "see" at once. Think of it as the model's working memory. Different models have different context window sizes:

  • GPT-4: ~8K-128K tokens (depending on version)
  • Claude 3.5 Sonnet: 200K tokens
  • Gemini 1.5 Pro: Up to 2M tokens

Practical Tip: When working with AI, prioritize what goes into the context window. The model pays most attention to the beginning and end of its context. Put the most important instructions at the start and end of your prompt.

Generative AI and Transformers

The "generative" in generative AI refers to the model's ability to create new content rather than just analyze existing content.

The Transformer Architecture

Almost all modern LLMs are built on the Transformer architecture, introduced by Google researchers in 2017 in the paper "Attention Is All You Need." The key innovation is the attention mechanism.

Attention allows the model to weigh the importance of different words in a sentence relative to each other. For example, in "The cat sat on the mat because it was comfortable," attention helps the model understand that "it" refers to "the cat," not "the mat."

Why Transformers Matter for Vibe Coding

The Transformer architecture is what makes tools like Cursor, Copilot, and Claude Code possible. It can handle long-range dependencies in code — understanding how a variable defined at the top of a file affects a function at the bottom. This is crucial for generating coherent, working software.

Why AI is Transforming Software Development

AI is reshaping software development in three fundamental ways:

1. Democratization

You no longer need to spend years learning to code to build software. Natural language becomes the programming language. Anyone with a clear idea can now build working applications.

2. Acceleration

Experienced developers using AI tools report 2-5x productivity gains. Boilerplate code, testing, documentation, and debugging — tasks that used to take hours now take minutes.

3. New Paradigm

The job shifts from "writing code" to "directing AI." Instead of implementing every function yourself, you describe what you want, review what the AI generates, and refine through iteration.

This is what "Vibe Coding" means: Moving from writing every line of code to directing an AI collaborator. Your value shifts from syntax mastery to problem definition, architecture thinking, and quality judgment.

The Current Landscape of AI Models

Understanding the players helps you choose the right tool for the job:

  • OpenAI (GPT-4, GPT-4o): Strong all-rounder, great for creative tasks, large ecosystem. Powers ChatGPT and many third-party tools.
  • Anthropic (Claude 3.5 Sonnet, Opus): Excellent for coding, reasoning, and safety. Powers Cursor and Claude Code. Known for large context windows.
  • Google (Gemini 1.5 Pro, Flash): Huge context windows (up to 2M tokens), strong multimodal capabilities, integrated with Google ecosystem.
  • Open-Source Models (Llama 3, Mistral, DeepSeek): Free to use, can be run locally, good for privacy-sensitive applications. May lag behind proprietary models on complex tasks.
  • Specialized: Models fine-tuned for specific tasks — code generation (Codex, StarCoder), image generation (DALL-E, Stable Diffusion), or music generation.

Recommendation: For vibe coding, start with Claude 3.5 Sonnet (for Cursor/Claude Code) or GPT-4o (for ChatGPT/Copilot). These have the best balance of quality, speed, and tool integration.

Glossary

AI (Artificial Intelligence) Machines performing tasks that normally require human intelligence
Machine Learning A subset of AI where systems learn patterns from data without explicit programming
LLM (Large Language Model) An AI model trained on vast text data to understand and generate human-like text
Token The basic unit of text that AI models process (~3/4 of a word)
Context Window The amount of text an AI model can process at once (its working memory)
Transformer The neural network architecture that powers modern LLMs, using attention mechanisms
Attention Mechanism A technique that allows models to weigh the importance of different parts of input text
Generative AI AI that creates new content (text, images, code) rather than just analyzing existing data

Exercises

📝 Exercise 1: Explain AI to a Friend

Write a one-paragraph explanation of what AI is, aimed at someone who has never heard of it. Avoid jargon. Use an analogy. The goal is to make the concept accessible — this skill of translating technical concepts is essential for vibe coding, where you need to communicate ideas to AI tools effectively.

~10 minutes

🔬 Exercise 2: Token Awareness

Take a paragraph of text (50-100 words) and guess how many tokens it contains. Then paste it into ChatGPT, Claude, or any AI chat and ask "How many tokens is this text?" Compare your estimate to the actual count. Repeat until your estimates improve. This builds intuition for managing context windows.

~15 minutes

💬 Exercise 3: Compare AI Responses

Ask the same question to two different AI models (e.g., ChatGPT and Claude). Try a question like "Explain how a transformer works in simple terms." Compare the responses. What did each model do differently? Which explanation was more helpful? This builds your ability to choose the right tool.

~20 minutes

🤔 Exercise 4: Spot the Difference

Think of a task you do regularly (planning a meal, organizing your calendar, writing an email). Describe how a rule-based system would handle it, then describe how a machine learning system would handle it differently. What advantages would each approach have?

~15 minutes
