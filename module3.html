Tool Categories

Vibe coding tools fall into several categories, each with different strengths. Most builders use a combination of tools from multiple categories:

  • Hosted Builders — Browser-based platforms where you describe your app and it builds live. Best for standalone projects and rapid prototyping.
  • AI IDEs — Code editors with AI deeply integrated. Best when you want more control and need to work with existing codebases.
  • CLI Agents — Terminal-based AI that can read, write, and refactor your code. Best for backend work and complex refactoring.
  • Backend Services — Managed infrastructure that handles databases, auth, and storage so you focus on features.
  • Deployment Platforms — One-click hosting for your vibe-coded projects.

Choosing Your Stack

Your tool choice depends on what you're building:

For Beginners (No Code Experience)

Start with Lovable or v0.dev for the frontend and Supabase for the backend. This combination handles 90% of what you'll want to build. No terminal or code editor needed.

For Intermediates (Some Technical Knowledge)

Use Cursor as your editor with GitHub Copilot for inline completions. Add Claude Code or Aider for complex refactoring. Deploy on Vercel.

For Experienced Developers

Combine Claude Code (or Aider) in the terminal with Cursor for editing. Use Supabase for backend, and deploy on Railway or Fly.io.

Pro Tip: Don't try to learn everything at once. Pick one tool from each category and master it. The best stack is the one you actually use to build things.

Exercises

🛠️ Exercise 1: Tool Comparison

Pick two hosted builders (e.g., Lovable and v0.dev). Give each the same prompt: "Build a one-page landing page for a productivity app called FocusFlow." Compare the results in terms of design quality, code structure, and ease of iteration.

~45 minutes

🔧 Exercise 2: IDE Setup

Install Cursor (or Windsurf). Open an existing project or create a new one. Use the AI chat to ask three questions about your code: "What does this project do?", "How is the routing structured?", "What are potential improvements?"

~30 minutes

🔄 Exercise 3: CLI Agent Trial

Install Claude Code or Aider. Give it a task: "Add a dark mode toggle to this HTML page" or "Create a new API endpoint that returns user data." Observe how the CLI agent approaches the task differently from a hosted builder.

~30 minutes

📋 Exercise 4: Stack Plan

Write down your current skill level and what you want to build next. Based on this module, choose one tool from each category (builder/IDE, backend, deploy) that fits your needs. Explain why you chose each one.

~15 minutes
